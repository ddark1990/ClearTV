# Security policy

Please **don't open a public issue** for security problems.

Report privately through GitHub's **Security > Report a vulnerability** on https://github.com/ddark1990/ClearTV. Include steps to reproduce and the ClearTV version (Settings > About).

Things we especially care about: leaks of sign-in tokens or cookies, the in-app update check (signing key and SHA-256), the domain lock, and anything that could make a service's page run outside its own domains.

We aim to reply within 7 days. Only the latest release gets fixes.
